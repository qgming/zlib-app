# 芝士读书 1.3.0

## 新增功能

- **完整英文界面**：支持跟随系统、简体中文与英语三种软件语言设置，同步适配主导航、搜索筛选、图书详情、书架、下载管理、账号、设置、提示与通知。
- **发现页「热门 / 推荐」标签**：首页顶部新增双标签切换，各自独立保留列表与滚动位置，下拉刷新仅更新当前标签。

## 体验优化

- **统一首页命名**：首页标题与底部导航由「阅读」更名为「发现」（英文 `Discover`）。
- **版本折叠日志**：更新日志支持按版本展开和收起，进入时默认仅展开最新版本。
- **开源许可折叠展示**：开放源代码许可按依赖逐项列出，默认全部收起、点击展开全文，移除顶部多余介绍与重复条目。
- **设置项调整**：「外观模式」更名为「主题模式」，新增的「软件语言」位于主题模式与网络格数之间。

## 问题修复

- **统一搜索拒绝提示**：搜索被服务端拒绝时，中文统一显示「Z-library 拒绝搜索」，英文显示对应提示，覆盖首屏搜索、作者搜索与分页加载。
