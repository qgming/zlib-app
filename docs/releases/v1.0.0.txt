芝士读书 1.0.0

功能

1、热门与推荐、关键词搜索，以及语言、格式、年份、精确匹配和排序筛选。

2、图书详情、简介与出版信息；点击作者或译者姓名继续搜索。

3、下载前选择服务端提供的文件格式；云端收藏与下载记录分页、刷新及独立管理。

4、本机书架直接读取已授权下载目录，支持外部阅读器打开、系统分享和确认后删除。

5、邮箱密码与 Cookie 登录、多账号加密会话、手动切换及额度展示，不保存密码。

6、持久化下载队列、暂停与恢复、重试、前台通知与断点续传。

7、域名管理提供自动切换开关、自定义域名、单独或全部体检及手动选择。

8、中文名称“芝士读书”与全新图标，Miuix 玻璃界面、深浅主题、可调封面网格。

9、设置及关于页统一卡片样式和间距，保留原生 56dp 最小行高；下载目录、域名管理独立。

10、关于页提供实际版本、真实发布日志、协议与隐私、开源许可及作者入口。

11、启动及手动检查 GitHub Release；应用内匹配架构下载、显示进度，校验后保存到下载目录，点击安装交系统确认。

优化

1、登录与添加账号共用表单，移除 WebView 登录。
