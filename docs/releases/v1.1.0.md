# 芝士读书 1.1.0

## 新增功能

- **全新搜索筛选菜单**：改为与设置一致的右侧选择菜单，语言与格式支持多选（默认全部），语言名称来自服务端返回；补全排序选项，出版年份置底。
- **自动加载下一页**：搜索、收藏与云端下载记录滚动接近底部时自动分页，加载失败保留已有列表并支持重试，到达末页或收到重复数据自动停止。
- **搜索状态恢复与最近搜索**：搜索条件支持系统重建恢复；本机最多保存 10 条最近搜索，支持点击复搜、长按删除单条及确认后清空全部。
- **相似图书推荐**：图书详情底部新增相似图书网格，沿用首页纵向封面样式，点击可继续浏览详情。
- **轻量短提示**：手动检查更新已是最新版与删除云端下载记录成功改为系统短提示。

## 体验优化

- **首次引导流程**：首次启动先授权下载目录再登录；已有目录自动沿用，目录失效时引导重新授权；启动账号资料刷新不再阻塞主界面。
- **安全切换下载目录**：切换目录前暂停并等待当前写入停止，保留原目录已有文件。
- **减少重复收藏请求**：同一账号内复用已确认的收藏状态，在刷新、切换账号或状态变更后重新核对。
- **通知直达下载管理**：点击下载前台通知可直接进入下载管理页面。

## 问题修复

- **强化续传完整性校验**：避免不完整的网络响应被错误标记为下载完成。
- **临时文件隔离与重名避让**：临时文件按图书引用隔离，成书文件重名时自动避让。
- **重复下载提示**：下载本地已存在的文件时支持选择直接打开或重新下载。
