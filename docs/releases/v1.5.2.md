# 芝士读书 1.5.2

## 新增功能

- **双评分展示**：搜索结果和图书详情在同一个胶囊中显示「兴趣评分 / 下载质量」，兴趣评分使用黄色，下载质量使用绿色；缺少其中一项时显示「—」，便于分别了解图书内容与文件质量。
- **内容语言本地化**：搜索结果增加内容语言标签，已知语言随软件设置显示为中文或英文，并保留简繁等已知差异；未知语言保留原文。

## 体验优化

- **搜索信息集中展示**：搜索结果的胶囊依次为双评分、出版年份、内容语言、文件格式和文件大小，共最多五项，统一在作者下方排列并随宽度换行；缺失信息不留空位。
- **下载按钮分区**：详情下载按钮左侧约 30% 用于查看全部版本，右侧约 70% 直接下载当前图书文件；已有本机文件时仍提示打开或重新下载。整个下载按钮与预览按钮等宽，窄屏下可换行显示。
- **隐藏无效年份**：搜索结果和详情不再显示值为 0 的出版年份，减少无效标签。

## 问题修复

- **修复搜索闪退**：修复部分图书搜索结果加载后应用异常退出的问题，提升搜索列表的稳定性。
