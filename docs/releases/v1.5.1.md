# 芝士读书 1.5.1

## 新增功能

- **本机 EPUB 书名与封面识别**：自动读取下载目录中 EPUB 文件内嵌的书名、作者和封面，手动放入目录的 EPUB 也可识别。信息缺失或文件不支持时，保留已有资料、文件名和默认封面。
- **已完成下载直接打开**：点击下载管理中的已完成图书，即可像「书架 → 本机」一样调用其他应用打开文件。

## 体验优化

- **搜索结果展示出版社**：在书名与作者之间增加出版社文字，方便区分不同版本；没有出版社信息时不留空行。
- **搜索标签更紧凑**：缩小评分、年份、格式和文件大小四个胶囊的内边距与间距，保留原有字号，让常见短标签更容易在一行显示，较长内容仍可自动换行。
- **本机文件渐进加载**：先显示文件列表，再补充 EPUB 信息与封面，复用未变化文件的识别结果；手动刷新可重新识别，减少较大目录中的重复读取。

## 问题修复

- **修复部分图书下载误报文件校验失败**：兼容部分镜像返回下载链接时响应类型标注错误或缺失的情况，正确解析链接后继续下载，并保留文件完整性检查。
- **完善文件丢失提示**：从已完成下载或本机打开文件时，若文件已不存在，显示「文件没有找到，可能已被删除」；目录授权异常和没有可用阅读应用时提供对应提示。
- **修复文件操作状态残留**：切换下载目录、账号或离开页面后，取消过期的打开请求，避免随后打开旧文件或出现旧提示；改善文件提供方读取中断后的清理与恢复。
