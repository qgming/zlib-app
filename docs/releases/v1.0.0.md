芝士读书首个正式版本。最低支持 Android 13。

阅读与图书

热门与推荐、关键词搜索，以及语言、格式、年份、精确匹配和排序筛选。
图书详情、简介与出版信息；点击作者或译者姓名继续搜索。
下载前选择服务端提供的文件格式；云端收藏与下载记录分页、刷新及独立管理。
本机书架直接读取已授权下载目录，支持外部阅读器打开、系统分享和确认后删除。

账号、下载与网络

邮箱密码与 Cookie 登录、多账号加密会话、手动切换及额度展示，不保存密码。
持久化下载队列、暂停／恢复／重试、前台通知与 Range 续传。
域名管理提供自动切换开关、自定义域名、单独／全部体检及手动选择。
精简登录和添加账号表单，移除 WebView 登录。

界面与更新

中文名称“芝士读书”与全新图标，Miuix 玻璃界面、深浅主题、可调封面网格。
设置及关于页统一卡片样式和间距，保留原生 56dp 最小行高；下载目录、域名管理独立。
关于页提供实际版本、真实发布日志、协议与隐私、开源许可及作者入口。
启动及手动检查 GitHub Release；应用内匹配架构下载、显示进度，校验后保存到下载目录，点击安装交系统确认。

安装包选择

arm64-v8a：64 位 ARM 手机和平板。
armeabi-v7a：支持 32 位 ARM 应用的 Android 13+ 设备。
x86_64 / x86：对应 Intel / AMD Android 设备或模拟器。
universal：包含以上四种架构，不确定时选择。

各包最低系统要求相同，包名和签名保持不变，附 SHA256SUMS.txt。从开发版覆盖安装后，旧版单账号会话可能需要重新添加；不会清除下载文件。

本应用为 Z-Library 非官方客户端，不内置阅读器，不提供图书内容或账号。仅访问和下载有权使用的内容；服务端接口、域名、账号限制与可用性可能变化。
