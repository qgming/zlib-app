# 芝士读书 1.0.0

## 核心功能

- **发现与搜索**：支持热门与推荐浏览、关键词搜索，以及语言、格式、年份、精确匹配与排序筛选。
- **图书详情**：展示封面、简介与出版信息，点击作者或译者姓名可发起关联搜索。
- **格式选择与云端记录**：下载前自由选择服务端提供的文件格式；云端收藏与云端下载记录支持独立分页、刷新与管理。
- **本机书架**：直接读取用户授权的下载目录，支持调用外部阅读器打开、系统分享及确认后删除真实文件。
- **多账号管理**：支持邮箱密码与 Cookie 导入登录、Android Keystore 加密保存多账号会话、手动切换与剩余额度展示，绝不保存密码。
- **可靠下载队列**：持久化顺序下载队列，支持暂停、恢复、重试、前台进度通知与断点续传。
- **域名管理**：支持自动切换开关、自定义域名、单独或全部体检及手动选择镜像。
- **视觉与主题**：中文名称「芝士读书」与专属图标，基于 Miuix 玻璃界面，支持深浅主题切换与可调封面网格列数。
- **设置与关于**：统一圆角卡片与行高规范，独立管理下载目录与域名；关于页提供版本信息、真实发布日志、协议与隐私、开源许可及作者入口。
- **应用内更新**：冷启动与手动检查 GitHub Release，自动匹配架构下载并展示进度，经签名与摘要校验后保存至下载目录，由用户确认交系统安装。

## 体验优化

- **统一登录体验**：登录与添加账号共用表单，移除 WebView 登录。
