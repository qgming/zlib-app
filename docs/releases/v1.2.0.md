# 芝士读书 1.2.0

## 新增功能

- **域名重定向自动发现**：内置域名跳转到允许清单外地址时，客户端先在无凭据状态下验证目标接口，通过后采用并切换；未通过时在原域名提示失败。
- **扩充内置域名**：新增 `zlib.re` 与 `z101.by`，内置域名清单扩充至十六个。
- **识别 DiamWall 验证**：域名体检可准确识别 DiamWall 人机验证，不再误报为重定向异常。
- **统一系统短提示**：全应用底部短提示统一为系统 Toast，覆盖本机文件操作、下载目录异常、账号与域名操作、关于页外链及更新安装反馈。

## 体验优化

- **体检与切换优先级重排**：直接返回接口数据的可用域名排在前列，需人机验证或证书异常的域名排在后列。
- **发现域精确校验**：自动发现的目标域名仅信任精确主机名，冷启动无凭据复检不通过则自动移除。
- **根路径跳转探测修正**：跳转目标指向站点根路径时改为请求接口端点，不再将网页正文视为探测结果。
- **锁定域名保持原卡片**：手动锁定的域名保持卡片状态不变，实际请求走已验证的跳转目标。
- **精简提示宿主**：移除整套底部条组件，每页仅保留单一 Toast 宿主，切换账号或目录时自动取消未消失提示。

## 问题修复

- **修复跳转域名误判**：解决跳转到允许清单外域名被直接判为无效、导致可用镜像无法使用的问题。
- **修复 DiamWall 误报**：解决 DiamWall 防护域名被误报为重定向异常的问题。
- **修复双重提示重叠**：解决更新页与云端下载记录同时出现两种提示，以及本机删除提示样式与检查更新不一致的问题。
