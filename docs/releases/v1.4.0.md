# 芝士读书 1.4.0

## 新增功能

- **我的书单**：从「设置」账号下方进入，浏览当前账号自己的云端书单；卡片展示四封面预览、书单名称与已知图书数量，支持下拉刷新、单内分页浏览与返回位置保留。
- **图书详情加入与新建书单**：在「查看更多评论」下方新增同宽整行「加入书单」按钮，可选择已有书单（已加入项清晰标记），也支持新建私有书单并同时加入本书。
- **图书评论查看**：详情页简介下方预览最多三条主评论，点击卡片查看全文与回复，「查看更多评论」进入列表；卡片展示头像、作者、时间、回复数与点赞数，详情按层级展示嵌套回复并标明「回复@作者：」。
- **在线预览**：支持在线阅读的图书在「下载」右侧提供「预览」入口，进入或刷新时按当前镜像实时获取阅读链接，支持刷新、复制公开链接与系统浏览器打开。
- **图书与书单图片分享**：在图书详情收藏右侧与自有书单详情顶栏点击分享，预览生成的 PNG 图片（底部居中保留软件图标与名称），支持「保存到本地」或调用系统分享。

## 体验优化

- **图书详情信息层次**：放大作者与译者行字号并保留姓名独立点击搜索；评分、出版年份、当前文件格式与大小改为自动换行的紧凑图标胶囊，缺项不占位。
- **长简介折叠与复制**：简介超过五行默认收起，支持上下箭头展开或收起，保留正文选择复制。
- **出版信息内嵌卡片**：置于评论及加入书单入口下方，集中展示出版社、语言、版次、页数、ISBN 与完整分类，出版社支持点击搜索。
- **顶栏收藏与格式菜单**：云端收藏调整至详情顶栏，已收藏显示红心；格式菜单将当前格式固定置顶，未返回其他格式或加载失败时仍保留当前格式。
- **评论与书单网络恢复**：临时网络故障支持自动重试，切换账号或镜像时自动清理旧数据，避免旧请求覆盖当前页面。
- **分享图多场景适配**：适配长标题、多语言、空书单及缺失封面，加载失败自动回退排版书封。

## 问题修复

- **在线预览异常**：修复部分镜像停留在 `Loading reader…` 以及阅读内容闪烁、空白的问题。
- **分类显示不全**：修复部分图书返回结构化分类数据时信息展示不完整的问题。
