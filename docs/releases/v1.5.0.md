# 芝士读书 1.5.0

## 新增功能

- **官方与社区镜像内置管理**：域名管理直接内置 **17 个官方镜像**与 **34 个社区镜像**，两组镜像均可直接体检、选择并参与启动自动恢复与切换，健康卡片同步展示实测往返延迟。
- **隔离网页手动人机验证**：遇到 DiamWall、Cloudflare、DDoS-Guard 等防壁垒验证的镜像时，可点击进入独立进程隔离网页手动完成挑战；验证页不写入账号凭据，退出自动清理网页数据，通过后仅在当前网络短时复用验证状态。
- **书单快捷移除**：在图书详情的「加入书单」面板中，点击已加入的书单即可直接将当前图书移出，无需跳转网页处理。
- **分享图浅色 / 深色切换**：图书与书单图片分享页顶栏右侧新增主题切换按钮，默认跟随当前应用主题，可实时切换浅色 / 深色画布并复用内存封面即时重绘。
- **更新日志 Markdown 渲染**：「检查更新」面板与「更新日志」页面支持解析并展示 Markdown 格式，涵盖标题、列表、引用、行内代码、加粗与链接，同时兼容历史纯文本日志。

## 体验优化

- **启动速度与智能选路**：启动时优先验证上次使用的域名，健康即刻进入；不可用时并发探测其余镜像，首个健康镜像返回即立即进入主界面，随后在后台一次性完成剩余镜像测速并按实测延迟优化排序权重。
- **搜索结果单列图文列表**：搜索结果由封面网格调整为单列图文布局，左侧保留 2:3 封面与共享元素转场，右侧清晰展示书名、作者 / 译者以及评分、出版年份、格式、文件大小等胶囊标签。
- **Miuix Glass 视觉升级与引导重构**：升级至 Miuix `0.9.5-rc01` 并全应用优先采用 Glass 玻璃质感；启动页新增居中透明软件图标与紧凑状态条，重构首次下载目录授权页与登录页排版层级。
- **玻璃底部面板布局优化**：修复全部玻璃底部面板内容与浮动顶栏重叠的问题，并将搜索筛选、加入 / 新建书单、添加域名等面板的操作按钮移至顶栏两侧，减少纵向占用。
- **分享图片排版重构与封面缓存复用**：移除图书分享图封面外层厚重卡片，优化图书与书单分享图的整体层次；优先复用详情页与书单页已加载的封面缓存，减少加载等待，并为封面加载增加超时保护。
- **评论子回复阅读优化**：取消评论详情中嵌套子回复的左侧层级缩进，保持全宽排版并继续以「回复@作者：」标明对象，提升窄屏阅读体验。
- **快捷交互与图标统一**：下载管理页右上角云端记录按钮改为与全站一致的空心云轮廓图标；云端下载记录与自定义域名长按不再经过单按钮面板，直接弹出二次确认对话框。
- **更新检查与缓存体验**：匿名查询遭遇网络异常或 GitHub 限流时，手动检查与查看日志统一使用短提示引导切换网络 / VPN 后重试，按当前默认网络分别记录限流等待时间，并支持清晰标示已缓存的发布信息。

## 问题修复

- **修复书单与评论误报人机验证**：PAPI 接口改为优先按 JSON 内容解析，解决部分镜像返回 `text/html` 响应头导致正常书单与评论被误判为人机验证的问题，并兼容省略分页信息的书单翻页。
- **修复域名安全授权边界**：未知跳转目标不再自动授信接收账号凭据，须由用户显式添加批准；密码表单严格禁止跟随跳转。
- **强化下载续传与文件交付恢复**：仅对经强 HTTP 验证器确认属于同一资源的字节范围执行断点续传，先记录交付证据再重命名或复制，进程异常中断后自动核对恢复，避免不完整文件进入本机书架。
- **完善分享保存失败清理**：通过系统文件选择器保存分享图失败或取消时，自动尝试清理本次新建的空白目标文档。
