# Roadmap

每个阶段以“可运行 + 可验证”为准，不按日期排期。v1 的 Definition of Done 见 `AGENTS.md` §9。

元数据编辑已按 ADR-030 取消，原 v0.6 阶段及后续格式/查源扩展均移出计划；EAPI 图书信息展示继续保留。
应用备份/恢复和独立本地书库已按 ADR-031 取消。“我的图书馆”的已下载、收藏、书单以 Z-Library 云端为准；本机文件归下载管理，云端书单先验证 EAPI 再实现。
ADR-032：书架仅“收藏 / 书单”，下载管理分别提供本机文件与云端下载记录入口；书单提示页不代表内容接入已完成。

## v0.3 — 搜索与详情

## v0.4 — 下载与书架

- [x] SAF 目录选择 + 持久化权限
- [x] 前台 `dataSync` Service + 通知 + 暂停/取消/恢复
- [x] Room 下载队列 + Range 续传 + `.part` 原子 rename
- [x] 重试/退避/配额保护
- [x] 本机文件列表、删除/分享（已迁入下载管理，见 v0.5）
- [x] 分享 `ACTION_SEND`（直接授予 SAF 文档 URI 读权限）

**验收**：真机已验证：JSON `file.downloadLink` 解析后下载真实 EPUB（4.4MB），EPUB 魔数校验通过，`Range: bytes=1000000-` 返回 206 并续传为字节一致的完整文件；书架可见、分享面板可打开。暂停/取消/断网重连/进程重启恢复仍需手测。
