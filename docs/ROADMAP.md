# 维护计划

当前发布基线为 **v1.3.1**。已发布功能与用户说明见 [README](../README.md)，每版变化见 [发布日志](https://github.com/qgming/zlib-app/releases)。本文件只保留后续工作，移除已经失效的 v0.x 分期与占位功能安排。

## 已交付范围

- 邮箱密码与 Cookie 登录、多账号加密会话、手动切换与指定账号退出、额度展示。
- 阅读发现、搜索筛选与分页、图书详情、作者搜索、下载前选择格式。
- SAF 下载目录、持久化顺序队列、暂停／恢复／重试、前台通知与续传。
- 书架本机文件及图书收藏、独立云端下载记录和确认删除；设置中的「我的书单」支持四封面卡片及单内图书分页，随会话隔离云端数据。
- 域名体检、自动／手动切换、自定义域名；独立下载目录与域名管理设置。
- Miuix 玻璃界面、深浅主题、可调网格、芝士读书图标及关于页面。
- GitHub 正式发布日志、启动／手动检查、应用内 APK 下载进度与用户确认安装。
- 正式通用 APK、SHA-256 校验文件和可重复执行的发布资产任务；从1.3.0起只生成含四种ABI的正式通用包，旧版独立架构发布记录保留。

## 后续验证与维护

各版本的验证事实见 [TESTING.md](TESTING.md)，发布与附件记录见 [RELEASING.md](RELEASING.md)。

- [ ] 支持 SharedView Kit 的 ROM 真机动画专项验证：首次打开／返回、手势返回、来源失效、旋转与进程重建。
- [ ] 多台真实设备：多账号切换、失效会话、多设备收藏／下载记录刷新与异常路径。
- [ ] 开发版书单：在真实会话验证设置入口、四封面预览、Cookie 导入、私有书单分页与会话隔离。范围见 ADR-079/084。
- [ ] 真实非空格式列表及选择不同文件后的下载验证；模拟映射通过不能代替真实样本。
- [ ] 断网、进程终止、SAF Provider 权限撤销、不可 rename 目录和通知拒绝的综合回归。
- [ ] 平板／分屏／横屏、五列窄封面、大字号及无障碍检查。
- [ ] 四种 ABI 的设备或模拟器覆盖；当前真机为 arm64-v8a，不声称所有架构均已实测。
- [ ] GitHub Actions 自动检查与签名发布。当前使用本机验证并手动发布，不展示尚不存在的 CI 状态。
- [ ] 第一次 Room schema 升级时提供 Migration 与迁移测试，禁止破坏性重建。

具体检查与验证事实保存在 [TESTING.md](TESTING.md)，版本与签名规则见 [RELEASING.md](RELEASING.md)。

## 范围边界

继续以 JSON EAPI 为主；我的书单按 [PAPI.md](PAPI.md) 使用限定的只读 PAPI JSON。不抓取目录、不绕过验证、不维护本地书单。公开书单、书单搜索、书单写入（含收藏）和评论不在本次范围。

不做应用备份／恢复、独立本地书库／书单及导入导出、本地元数据编辑或第三方查源、内置阅读器、Kindle 推送、微信读书导入 API、多书源、MCP、TUI 和静默安装。系统分享及登录 Cookie 导入继续保留。
