## 2. 必测行为

### 2.1 安全

- 跨 host 重定向后，`Cookie` / `remix-userid` / `remix-userkey` 被剥离。
- 非 allowlist 域名被拒绝；`http://`、端口、路径、IP、单标签主机被拒绝。
- 日志中不出现密码、Cookie、remix key、完整签名下载 URL。
- 退出指定账号清空该账号内存/加密会话，不清除其它账号；不保留 WebView 登录和 CookieManager 代码。
- `allowBackup=false` 与 data extraction rules 禁止系统备份和数据迁移；应用不提供备份/恢复入口，登录 Cookie 导入继续保留。

### 2.2 域名

- 200 JSON `success:1` + domains → `HEALTHY`。
- HTML challenge → `CHALLENGED`。
- 513/517 或 DiamWall 标题 → `DIAMWALL`。
- 自重定向/超过 10 跳 → `REDIRECT_LOOP`。
- 超时/连接失败 → `NETWORK_ERROR`。
- 切换域名后 Cookie 仍可用。
- 域名页首项为自动切换开关，顶栏依次全部体检／添加域名；卡片统一圆角与切换／单独体检图标，48dp 触摸区和无障碍说明。添加底部面板失败保留输入，成功关闭；自定义域名长按删除。
- 单独体检仅更新目标状态、不切换；关闭自动切换后手动选择更新锁定目标，全部体检和重启不改变选择；开启后允许健康域名回退。初始化就列出未检测域名，非法或未允许域名不发请求。
- 登录页只保留密码和 Cookie 两种方式，按钮均满宽，不显示多余说明；切换方式清空密码／Cookie。当前域名右侧为更换纯图标，打开底部面板后点选指定项切换，错误留在面板且不换成其它项。

### 2.3 下载

- 206 续传、200 重下、Content-Disposition 文件名清洗。
- `.part` 完成前不出现最终文件；rename 失败走 copy+delete。
- 逐进程恢复：`DOWNLOADING` 重置为 `QUEUED`，校验 `.part`。
- 配额错误不重试；502/503/504 退避；4xx 不重试。
- 前台服务通知可暂停/取消；Android 13+ 通知权限。
- 下载卡片无封面，右侧水平排列暂停／继续／重试与 X，X 始终在最右侧，包含失败／取消项；已完成仅 X。X 移除任务记录，目标正在写入时先取消网络并等待协程及流关闭，清理未完成临时文件；其它任务继续，已完成文件及 URI 关联保留。控制指令不递归发送，连续操作不启动多个写入者。
- 详情点击“下载图书”只读取 `/formats` 并打开菜单，不提前解析下载链接或入队。完整映射非空选项、文件大小与独立引用；相同扩展名但不同引用全部保留，当前格式按引用去重；选择后以所选引用入队且重复点击只创建一个任务。
- 空格式数组直接列出当前文件，不显示“未返回其他格式”小字；错误明确展示并能重试，菜单关闭／退出账号后旧请求不能回写。再次打开重新请求，若服务端改为返回 PDF／MOBI 等其它扩展名，全部加入菜单，不被详情的 EPUB 属性过滤。真实非空格式样本与实际文件下载需另行验收，不以模拟响应代替。

### 2.4 我的图书馆（ADR-031/032）

- 书架顶部仅“本机 / 收藏”，首次默认本机；书单入口、页面、模块和依赖均移除，不发起书单请求。
- 云端已下载/收藏通过已记录的 EAPI 读取，分页和刷新不混入本机文件；其他设备的下载记录不标为本机可分享。
- 云端下载记录从下载管理独立进入，明确名称，保留分页/刷新；本机任务记录不与云端记录混淆。
- 缺失封面或 `collections//…` 等已知无效地址按可见卡片请求详情，最多 3 并发；成功仅更新封面并保留 `date_download` / 兼容日期，不添加本机文件 URI；失败不丢图书、不重复请求同本，图片不带账号凭据。
- 收藏刷新失败后仍能重试，追加分页保留既有数据与补取封面，不重复图书。
- 详情收藏从服务端读取，逐页查找数字 ID（包括无 hash 的收藏项）；无法完整读取时状态为未知，禁止写入。save/unsave 失败不改收藏状态，成功后刷新书架；重复点击只发一条写请求，账号切换清除状态。
- 删除云端下载记录不删除本机文件，删除本机文件不请求删除云端记录。
- 云端记录长按打开“删除记录”菜单，二次确认前不发送写入；成功只发送一次反馈、移除该数字 ID 并刷新第一页，失败保留记录和重试。刷新失败后不能使用旧偏移追加；写入 GET 的 5xx、会话错误或重定向均不自动重放。
- 删除菜单、格式菜单、详情信息面板和搜索筛选统一避让手势条／三键导航栏，底部额外 16dp 间距不重复添加；横屏刘海、长内容滚动和键盘展开时末尾操作可见。
- 云端删除成功仅显示与检查更新一致的无按钮系统 Toast，不出现顶部“记录提示”或“知道了”（ADR-064）；失败不发送成功消息。退出页面取消提示，会话代次变化重建宿主并清空未消费事件。
- 账号退出/切换后，上一账号的图书馆状态及缓存不可展示给下一账号。
- 书单模块已移除，不保留占位入口或未验证请求。
- 本机文件从书架本机操作，读取当前 SAF 下载目录及子目录真实文件；没有 Room 记录的支持格式也要显示，Room 中文件已丢失的记录不能显示。`.part`、图片、目录和 Provider 未完成文件不显示，同名不同 URI 不合并；文件名大小写扩展名正确识别。
- 文件外部新增／删除后监听通知或可见期间 3 秒核对更新，手动刷新、返回前台、下载完成、目录变更均重扫；离开停止监听和核对。目录未选／读取失败／权限失效有准确提示，不显示旧目录文件。
- 本机删除经二次确认后实际删除 Provider 文档并校验不存在，再清理精确 URI 关联；删除失败或 Provider 虚报成功时保留记录并可重试；目录变更后旧选择不能打开／删除，目录外 URI 不能删除。清理已完成任务不删除实际文件，云端记录无法恢复文件或 SAF 授权。
- 外部打开／分享前检查文件仍属于当前目录且可读，给接收应用只授予单个 URI 的临时读权限；没有阅读器／权限撤销时可恢复，不伪造 EAPI 引用或自动查源。
- 本机长按菜单“分享文件 / 删除本机文件”之间有 12dp 间距，保留面板安全区；小屏/大字号可用。

### 2.6 多账号（ADR-051）

- 只读新账号容器，不兼容旧单会话；退出旧版本后升级需要重新登录，不清除本机文件/任务。多个账号、资料、当前 ID 和自动切换开关都加密，密码不写入容器。
- 添加前验证登录和 profile，失败不替换当前账号；相同用户 ID 更新会话不重复添加。标准/Premium 标签仅来自 `isPremium`，字段缺失不推断；未知额度显示破折号而非 0。
- 账号名称/标签/邮箱/额度圆环在同一卡片。加号打开底部添加面板，密码和 Cookie 仅存在内存，关闭/完成清空；长按卡片菜单刷新和退出相隔 12dp，退出需确认。
- 手动切换前暂停并等待活动下载停止，只让后续请求采用新账号；文件 URL 解析和 CDN 使用相同会话快照，跨 host 请求完全剥离凭据。退出非当前账号不打断当前传输；退出当前选另一个有效账号，全部退出回登录。
- profile 返回按完整会话快照及用户 ID 隔离，旧响应不能清除/污染当前账号；重新登录后旧请求不能把新凭据标失效。收藏/云端记录/详情/推荐清理旧状态，搜索保留输入但清空旧结果。
- 自动切换默认关闭，明确额度错误后先读当前 profile 确认剩余 0，再核对候选剩余额度，未知/认证/网络/风控错误不作为切换依据。每任务每账号至多尝试一次；手动选择或关闭开关优先于在途响应；无候选时额度失败并暂停其它活动任务，禁止无限循环/自动登录/创建账号。风控不做免封禁保证，不主动耗尽真实账号额度测试。

### 2.5 图书网格与阅读首页（ADR-034/036/037/038）

- 首页/推荐、搜索、收藏、云端下载记录、本机文件共用无卡片网格，仅“2:3 封面 + 单行书名”，超长末尾省略；正常图、窄图、宽图和缺图同尺寸，图片不拉伸。
- 自动列数以当前布局宽度为准：359/360、599/600、839/840dp 分别切换 2/3/4/5 列；常见手机三列，手动 2/3/4/5 列覆盖自动规则，缺失/未知设置回退自动，选项仅“自动”。
- 选择立即作用于所有网格，重启保留；旋转/分屏重新计算自动列数，网格刷新、翻页及顶底栏安全区正常。
- 云端图书点击封面/书名进入详情，本机点击外部打开，完整书名保留在无障碍语义；本机长按分享/删除，删除必须二次确认。
- 图片缺失/失败/加载中使用实际书名和作者的经典书封，作者缺失显示“作者不详”，真实封面成功后替换；五列窄封面及详情大封面不溢出，图片请求不新增凭据。
- 阅读首页顶栏/底部名称一致，底部为 Glass 系列的 Notes 图标，与书架书本区分。双击阅读回顶部并展开顶栏；单击保持正常切换，间隔超时或切换其它 tab 后不误触，返回首页仍保留滚动位置。
- 设置全部选项无左侧图标及预留空间，顺序为账号、外观、下载目录、域名管理、关于；设置分组与下载任务卡片圆角 24dp，卡片内无行间分割线，其它页面卡片不变。账号主标题显示名称、副标题显示邮箱，缺失字段显示提示，点击继续进入账号页。
- 阅读／书架／设置切换使用整页宽度的横向滑动，标题、顶栏操作和书架分组共同移动，不叠加淡入淡出，底栏固定；正反方向与导航顺序对应，同 tab 重复点击不重播，快速切换不崩溃或串滚动状态，双击回顶仍可用，系统关闭动画时跟随关闭。
- SharedView Kit：默认尝试 ROM 能力、不增加设置项；公开能力查询、SCREEN/WINDOW 元数据、启动和返回坐标一致、8dp 转 px 的圆角；缺失能力及 back/fallback 各自的支持集合有 JVM 测试。图书详情通过非导出 Activity 打开，设备不支持和快照失败仍可打开／返回，连续点击只启动一次。
- 详情来源基本信息可先呈现，完整详情读取前不允许下载；收藏仍从云端确认，加载失败可重试。返回后原列表滚动位置保留，进程／配置重建不依赖仍在内存的来源快照。
- 详情下载按钮右侧显示“添加收藏 / 已收藏”，无操作区外层卡片、默认首次下载提示和页面内出版信息卡；已收藏点击仍取消收藏，未知状态／请求中禁用，失败不伪造状态，实际下载结果继续显示。右上角按钮及面板标题为“书籍信息”，出版社／出版年份／语言／版次／页数／ISBN／分类可滚动和复制，不展示文件格式和大小；这些属性仍在下载选项中显示，返回键优先关闭面板。
- 简介兼容普通文本、CRLF／Unicode／字面转义换行、HTML 段落／换行／列表／强调与字符实体，长文本不截断，可选择复制；脚本、样式、图片与链接行为不进入渲染或触发请求，段落不粘连且过量空行被收敛。格式转换有 JVM 回归测试，实际排版用真机验收。
- 作者与译者各姓名独立为蓝色可点击文本，国籍／角色／分隔符普通样式；点击只搜索该姓名，不带其他标记或继承旧筛选。姓名中的空格、中点、连字符保留；自动搜索只初始化一次，返回后保留查询、页码和滚动位置，结果可再打开详情并逐层返回。书名 SemiBold（600），仅姓名链接 Medium（500），不改变字号。拆分范围与搜索初始化有单测和 MockWebServer 回归。

## 4. MockWebServer 约定

- 每个测试用独立 `MockWebServer`；`baseUrlProvider` 指向它。
- fixture 放 `src/test/resources/eapi/`，命名 `login_success.json`、`search_page1.json`、`download_302.json` 等。
- 下载测试用本地临时文件作 `DownloadSink`，不要写真实 SAF。
- 重定向测试显式设置 `Location`，并断言第二跳请求头已剥离凭据。

## 7. ADR-060–063 回归（2026-11-23）

- 首次无目录时先显示目录选择，取消仍留在引导；成功持久授权后进入登录。已有目录不重复引导，失权后可从设置/失败任务重新授权；profile 网络延迟不阻塞已有会话界面。
- 同名不同引用的 part 及清理互不影响，200覆盖/206区间起点及终点/短响应/416/未知长度不误报完成；rename不支持时复制可取消，失败保留part。
- 下载中切换目录先停止旧写入，原目录文件保留；新目录恢复时不沿用旧目录偏移。已有精确引用提供打开与明确重新下载，已有文件保留。
- 搜索条件恢复重查第一页，不重复作者初始化或恢复其它账号结果；最近搜索默认记录、上限10/去重/长按删除，右侧纯图标清空需二次确认，取消保留记录；无记录开关或底部引导小字；语言直接使用API返回名称、可检索，不做特殊映射。语言/格式右侧多选菜单、空选表示全部，排序右侧单选菜单，出版年份最后；断网默认筛选仍可用，8种排序提交精确值。
- 搜索/收藏/云端记录自动分页，末页、空页、重复页停止；追加错误保留内容且不自动重试，手动重试正确页。删除后刷新失败不得沿用旧分页。
- 相似图书只请求一次无分页端点，去重/排除自身/缺字段/空列表/失败独立重试，纵向网格与详情共用滚动，点击与返回位置正确。
- 收藏短缓存跨账号隔离，失效及写入后重查，过期后读取服务端；本机扫描debug日志仅目录数/条数/耗时，无URI和文件名。大目录性能结论需实际测量。

本节为验收要求，自动化与模拟器事实见下文；不能等同于多台真机与多Provider验证通过。

## 8. ADR-064 回归

- 应用实际版本为1.1.0（versionCode=3），包名和签名保持一致；尚未发布时不伪造GitHub最新版本。
- 手动检查已是最新版时只出现一次Toast，不出现底部面板或加载面板；连续点击合并请求。自动检查已是最新版不提示，自动检查中手动点击仍只发一条请求、结束后给一次Toast。
- 发现新版、手动检查失败/限流/暂无发布继续显示可操作结果面板，不能当成已是最新版。
- 云端删除成功与检查更新共用ZlibToastHost；失败仍在确认面板显示错误，页面退出和账号切换取消当前Toast并丢弃旧账号未消费事件。
